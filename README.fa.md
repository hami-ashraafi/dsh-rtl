# dsh-rtl — چت راست‌به‌چپ برای DeepSeek Harness

[English](README.md) | فارسی

متن پیام‌های چت در DeepSeek Harness با جهت پایهٔ چپ‌به‌راست رندر می‌شود. برای فارسی (و عربی)
این یعنی جمله‌ها چپ‌چین می‌شوند و نقطه، پرانتز و علامت‌های پایانی سر جای اشتباه می‌افتند. این
باندل کوچک همان را درست می‌کند: ناحیهٔ گفت‌وگو و کادر نوشتن راست‌به‌چپ می‌شوند، ولی چیدمان
خودِ برنامه (سایدبار، تب‌ها، تولبار، تنظیمات) دست‌نخورده می‌ماند.

## چه چیزی عوض می‌شود

| بخش | قبل | بعد |
| --- | --- | --- |
| پیام‌های دستیار (Markdown) | چپ‌به‌راست، چپ‌چین | راست‌به‌چپ، راست‌چین |
| حباب پیام شما | چپ‌به‌راست، چپ‌چین | راست‌به‌چپ، راست‌چین |
| لیست‌ها داخل پیام | بولت و تورفتگی سمت چپ | بولت سمت راست، تورفتگی آینه‌شده |
| بلوک کد، کد درون‌خطی، فرمول | چپ‌به‌راست | چپ‌به‌راست و `isolate`، تا نقطه‌گذاری‌شان ترتیب جملهٔ فارسی را به‌هم نزند |
| کادر نوشتن | چپ‌به‌راست | راست‌به‌چپ هنگام تایپ فارسی |

## نصب

بدون هیچ مرحلهٔ build؛ مثل هر پلاگین دیگر DSH نصب می‌شود.

**از همین مخزن:**

1. در سایدبار سمت چپ روی **Plugins** بزنید.
2. **Add plugin** → این آدرس را پیست کنید:
   `https://github.com/hami-ashraafi/dsh-rtl`
3. نصب کنید و بعد باندل **Right-to-left Chat** را روشن کنید.

**از پوشهٔ محلی روی دیسک:** همان مسیر، فقط به‌جای آدرس مخزن، مسیر مطلق پوشه را پیست کنید.

اگر مدیر پلاگین گفت `restart-required`، برنامه را ببندید و دوباره باز کنید.

## حذف

**Plugins** → **Right-to-left Chat** → **Remove**.

هیچ فایلی از نصب اصلی هارنس دست نمی‌خورد؛ حذف پلاگین کافی است.

## سازگاری

برای DSH نسخهٔ `0.2.1-rc.3` (دسکتاپ و وب) نوشته شده. این پلاگین فقط ظاهر را عوض می‌کند و به
هیچ API داخلی وابسته نیست، پس تا وقتی ساختار DOM چت عوض نشود، به‌روزرسانی‌ها آن را نمی‌شکنند.
اگر نسخه‌ای نام کلاس‌های چت را عوض کند، فقط یک سلکتور در `client.js` باید اصلاح شود.

## چطور کار می‌کند

`package.json` سه چیز را اعلام می‌کند که هارنس بدون اجرای کد می‌خواند:

- `dsh.bundle.patch` → این پکیج یک **باندل** است و `cordis.patch.yml` ردیف `dsh-rtl` را به
  ترکیب پروفایل اضافه می‌کند.
- `dsh.client` → ماژول Client هنگام بالا آمدن رابط وب بارگذاری می‌شود.

`client.js` یک فکتوری تنبل است که فقط یک `<style>` در صفحه ثبت می‌کند و هنگام غیرفعال‌شدن
پاکش می‌کند. سلکتورها روی قلاب‌های پایدار نوشته شده‌اند (نه هش‌های CSS ماژول):

- `[data-slot="conversation.chat.flow"]`، `[data-chat-turn]`، `[data-conversation-scroll]`
  برای محدود کردن به ناحیهٔ گفت‌وگو؛
- کلاس‌هایی که `markdown` یا `bubble` در نامشان هست، برای متن پیام و حباب کاربر؛
- `[data-composer-seat]` برای کادر نوشتن؛
- `pre`، `code`، `.md-code-block` و `.katex` برای این‌که محتوای فنی چپ‌چین بماند.

## عیب‌یابی

| نشانه | علت احتمالی | راه‌حل |
| --- | --- | --- |
| بعد از نصب هیچ تغییری نیست | باندل روشن نشده | در Plugins کارت **Right-to-left Chat** را روشن کنید |
| فقط بخشی راست‌چین شده | سلکتور آن بخش با نسخهٔ DSH شما نمی‌خواند | یک ایشو باز کنید و بگویید کدام بخش (پیام، ابزار، خطا…) |
| همه‌چیز راست‌چین شده، حتی انگلیسی‌ها | رفتار عمدی است | اگر می‌خواهید انگلیسی‌ها چپ بمانند، بگویید تا حالت خودکار اضافه شود |
| کدها به‌هم ریخته | نسخهٔ قدیمی پلاگین | نسخهٔ فعلی `unicode-bidi: isolate` دارد؛ دوباره نصب کنید |
